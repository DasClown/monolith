# Legal launch checklist

This is a checklist, not legal advice.

- [ ] Impressum with name, address, email, responsible person
- [ ] Datenschutzerklärung covering Supabase auth, cloud saves, Paddle, logs
- [ ] AGB for digital content and virtual items
- [ ] Widerrufsbelehrung and digital-content consent flow
- [ ] Refund and chargeback process
- [ ] Account deletion and data export
- [ ] VAT, invoices, and merchant-of-record setup
- [ ] Age rating and youth-protection review
- [ ] Support email and response target
- [ ] Cookie/analytics consent if analytics are added
- [ ] Terms for player names and moderation
